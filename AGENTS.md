# AGENTS.md

A collection of agent skills in the open Agent Skills format, installable in
any harness. Read this before changing anything.

## Layout

| Path | Holds |
| --- | --- |
| `skills/<name>/SKILL.md` | Each skill, once. The only copy. |
| `drawer.json` | The one list of skills: name, version, summary, category, keywords. |
| `.claude-plugin/marketplace.json`, `gemini-extension.json`, the skills table in `README.md` | Generated by `tools/build.py` from `drawer.json`. Never edit by hand. Codex reads the Claude marketplace. |
| `install.sh` | The `curl` installer, POSIX `sh`. |
| `research/` | Notes and sources behind each skill's rules. |
| `tools/` | `build.py` (manifests), `check.sh` (every check), `setup.sh` (hooks), and the tests of `build.py` and `install.sh`. |

## Rules

- **One copy of each skill.** Never duplicate a `SKILL.md` into a harness's
  folder in this repo; manifests point at `skills/`.
- **Harness-agnostic skills.** A skill never depends on one harness's tools
  (no "use the Task tool"). Say what to do in plain terms; mention a specific
  tool only as one option among several.
- **Frontmatter is the contract.** One field per line, the value plain or
  wholly quoted, so every harness reads it alike. `name` matches the folder (lowercase,
  hyphens, at most 64 characters); `description` says what the skill does and
  when to use it, in at most 1024 characters. Agents choose skills from the
  description alone.
- **Grounded rules.** A rule in a skill should trace to a source or a real
  failure, recorded in `research/`.
- **After any change:** run `tools/check.sh`; it must pass before a commit.
- **Versions are per skill.** Raise a skill's version in `drawer.json` when
  its files change, then run `tools/build.py`: marketplace users only receive
  a change when the version moves. Patch for fixes, minor for new behaviour,
  major for a change that breaks how people use it. One raise covers every
  commit before a push; `check.sh` fails until it is done, on any branch. The
  repository has no version of its own; Gemini's extension version is derived
  from the skills'.
